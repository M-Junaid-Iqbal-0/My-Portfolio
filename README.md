# Muhammad Junaid Iqbal Portfolio

Responsive portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — responsive styling and sticky-header anchor offsets
- `script.js` — safe smooth navigation and reveal effects
- `assets/` — resume PDF

## Publish on GitHub Pages
1. Extract this folder.
2. Create a public repository named `M-Junaid-Iqbal-0.github.io` (or use an existing repository if you prefer a project URL).
3. Upload the **contents** of this folder, ensuring `index.html` is in the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
6. Wait for the deployment and open `https://M-Junaid-Iqbal-0.github.io/`.
